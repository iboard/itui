- Define simple forms to fetch parameters for the commands.

- Extract the repo layer and rewrite it to implement Ecto for the existing data schemas and json-files.
- For a MVP menue, implement a menu to run disk-free, uptime, free.
- For a MVP for the forms and data layer implement a simple todo application.
